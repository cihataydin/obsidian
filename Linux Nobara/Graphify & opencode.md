
İlk olarak opencode asistanının proje mimarisine (Graphify çıktısına) göre çıktı vermesi için aşağıdaki komutu çalıştır. Bu komut ilgili projede sadece bir kez çalıştırılmalıdır.

```sh
graphify opencode install
```

Şimdi ilgili proje dizininde terminal ile asistan çalıştır,

```sh
opencode
```

Projenin mimarisinin çıktısını alalım, bu komut proje geliştirildikçe tekrar çalıştırılmalıdır. 

```opencode
/graphify .
```

Asistan geliştirme yapmaya hazır.
